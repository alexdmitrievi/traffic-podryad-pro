# `@traffic/website`

Публичный сайт на Astro, SSG: `pipupi.ru`. Статьи, страницы кластеров и регионов,
продуктовые страницы четырёх линий услуг, CTA-формы, правовые страницы.

**Состояние: каркас воркспейса.** Исходников пока нет — приходят в Wave 4.

Обязательные правила ([../docs/WEB_SURFACES.md](../docs/WEB_SURFACES.md)):

- SEO-критичное содержимое присутствует в исходном HTML;
- чистый SSG: ни ISR, ни SSR в MVP;
- `canonical` всегда указывает на форму без `www`;
- сторонних счётчиков и пикселей нет.
