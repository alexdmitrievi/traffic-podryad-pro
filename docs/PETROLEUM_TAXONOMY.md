# Товарная таксономия: нефтепродукты

Первая тестовая ниша — **оптовая дистрибуция нефтепродуктов**. Этот документ задаёт справочники продуктов и регионов для сидов и — что важнее — **правила достоверности**, которые в этой нише строже обычных.

> ## ⚠️ Главное правило
>
> **Не выдумывать технические характеристики, марки, нормативы, стандарты, условия поставки, цены и юридические утверждения.**
>
> Приведённые ниже категории — это **навигационная структура каталога**, а не справочник спецификаций. Здесь намеренно нет числовых характеристик, требований стандартов, температурных диапазонов, плотностей, содержания серы, ценовых ориентиров и условий поставки. Такие данные вносятся только из подтверждённого источника и только человеком.
>
> **Любой материал этой ниши проходит фактологическую проверку человеком до одобрения** — шаг 12 конвейера в [CONTENT_PIPELINE.md](CONTENT_PIPELINE.md). Это не формальность и не пропускается.

## 1. Категории продуктов

Начальный набор `product_categories`. Это верхний уровень каталога — то, по чему человек ищет и по чему группируется контент.

| Код | Категория |
| --- | --- |
| `diesel_fuel` | Дизельное топливо |
| `gasoline` | Бензины |
| `fuel_oil` | Мазут |
| `bitumen` | Битумы |
| `lubricants` | Масла и смазочные материалы |
| `lpg` | Сжиженные углеводородные газы |
| `kerosene` | Керосины |
| `heating_oil` | Печное топливо |
| `marine_fuel` | Судовое топливо |

Набор открыт: категория добавляется, когда появляется реальный спрос в ключевых запросах, а не заранее «чтобы было».

## 2. Продукты внутри категорий

Таблица `products` хранит конкретные позиции: название, категорию, единицу измерения, синонимы для разметки ключевых запросов.

**Что заполняется:**

| Поле | Источник |
| --- | --- |
| `name` | Общепринятое наименование позиции |
| `category_id` | Категория из раздела 1 |
| `unit` | Единица измерения: тонна, литр, кубический метр |
| `synonyms[]` | Варианты написания и разговорные формы — нужны для автоматической привязки ключевых запросов |

**Что не заполняется автоматически и не генерируется моделью:**

- технические характеристики любого рода;
- ссылки на стандарты и нормативы;
- температурные, плотностные и любые иные числовые параметры;
- цены и ценовые диапазоны;
- условия и базисы поставки;
- утверждения о применимости к конкретной технике.

Конкретные марки и обозначения вносятся человеком из подтверждённого источника. Пока источник не подтверждён — позиция существует под общим наименованием категории, и это нормальное рабочее состояние.

## 4. Базисы поставки

Справочник вариантов для поля формы. **Это список пунктов выбора в интерфейсе, а не описание коммерческих условий.**

Наполняется человеком из реальной практики компании. Ни одно значение здесь не подразумевает и не описывает обязательств, сроков, ответственности сторон или порядка расчётов — за этим стоит договор, а не справочник в базе.

## 5. Правила достоверности

### Запрещено публиковать

- выдуманные технические характеристики и марки;
- выдуманные ссылки на нормативы и стандарты;
- выдуманные условия и базисы поставки;
- цены и ценовые диапазоны без подтверждённого источника;
- утверждения о законодательстве без проверки;
- гарантии качества, сроков и результата, которые компания не может обеспечить.

### Правило разрешения сомнений

**Утверждение, которое некому подтвердить, удаляется — а не смягчается формулировкой.**

Приписка «примерно», «обычно», «как правило» к выдуманному числу оставляет число выдуманным и добавляет к ошибке ложную уверенность. Пустое место в тексте честнее правдоподобной выдумки.

### Что модель делает и чего не делает

| Модель делает | Модель не делает |
| --- | --- |
| Структурирует материал | Не является источником фактов |
| Пишет связный текст | Не подтверждает характеристики |
| Предлагает план и заголовки | Не проверяет нормативы |
| Формулирует уже проверенное | Не устанавливает цены |
| **Расставляет явные маркеры мест, требующих проверки** | Не заменяет отраслевую экспертизу |

Требование к промптам конвейера: модель обязана **явно помечать** места, где ей потребовался бы факт, — маркером для человека, а не правдоподобной подстановкой. Отсутствие маркеров в черновике на техническую тему — само по себе повод для подозрения.

### Почему здесь строже, чем обычно

В большинстве ниш выдуманный факт — репутационная неприятность. В оптовой торговле нефтепродуктами неверная характеристика в публичном материале может быть воспринята как коммерческое предложение или как утверждение о свойствах товара. Цена ошибки здесь другая, поэтому и порог другой.

## 6. Чек-лист фактологической проверки

Проходится **до** одобрения, для каждого материала ниши:

- [ ] Все названия категорий и позиций соответствуют справочнику
- [ ] Ни одна техническая характеристика не появилась без подтверждённого источника
- [ ] Ни одна ссылка на норматив или стандарт не появилась без проверки
- [ ] Ни одна цена и ни один ценовой диапазон не указаны без источника
- [ ] Ни одно утверждение об условиях поставки не выходит за рамки реальной практики компании
- [ ] Ни одно утверждение о законодательстве не осталось непроверенным
- [ ] Ни одной гарантии, которую компания не может обеспечить
- [ ] Все маркеры «требует проверки», оставленные моделью, сняты — подтверждением или удалением фрагмента
- [ ] Регион и продукт в разметке материала соответствуют его содержанию

Невыполненный пункт блокирует одобрение. Не «отмечается для последующей доработки» — блокирует.
