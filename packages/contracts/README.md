# `@traffic/contracts`

Единственный источник правды для payload'ов API, DTO и формы ошибок. Zod-схемы.

**Состояние: каркас воркспейса.** Схем пока нет — приходят в Wave 3.

Новый эндпоинт начинается здесь. Backend валидирует этими схемами запросы и генерирует из
них OpenAPI; `webapp` использует их же в формах и клиентах.

Пакет не импортирует backend, поверхности, фреймворки и SDK провайдеров — это проверяется
правилом `contracts-dependency-direction` в `bun run architecture:check`.
