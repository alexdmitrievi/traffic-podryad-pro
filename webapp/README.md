# `@traffic/webapp`

React CSR-приложение за авторизацией: `app.pipupi.ru`, включая `/admin/*`.

**Состояние: каркас воркспейса.** Исходников пока нет — приходят в Wave 4.

Что живёт здесь, а что на публичном сайте — [../docs/WEB_SURFACES.md](../docs/WEB_SURFACES.md).
Короткое правило: страница за логином и без нужды в SEO — сюда; страница, которая должна
ранжироваться или красиво превьюиться, — в `website`.

Схемы приходят только из `@traffic/contracts`. Формы API руками не переписываются.
